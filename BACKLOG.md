## Technical Requirements

### HTML

* Использовать HTML5.
* Использовать семантически понятную структуру HTML.
* Использовать подходящие семантические элементы (`article`, `h1`, `button` и т. д.).
* Не использовать HTML-элементы только для визуального позиционирования.
* Не дублировать структуру карточки для каждой фасовки.

### CSS / SCSS

* Использовать CSS или SCSS.
* Использовать Flexbox и/или Grid.
* Реализовать адаптивность для 1440 / 768 / 375 px.
* Не использовать Bootstrap.
* Не использовать готовые шаблоны интернет-магазинов.
* Не использовать избыточное абсолютное позиционирование.
* Избегать дублирования CSS.
* Обеспечить корректное поведение на промежуточных ширинах.

### JavaScript

* Использовать JavaScript без frontend-фреймворка.
* Хранить данные фасовок в структурированном виде.
* Хранить текущее выбранное состояние фасовки отдельно от представления.
* Обновлять цену, старую цену и артикул при выборе фасовки.
* Обновлять визуальное состояние выбранной фасовки.
* Не реализовывать реальную корзину.
* Не добавлять сложную state-management архитектуру.

### Accessibility

* Использовать семантические интерактивные элементы.
* Обеспечить возможность выбора фасовки с клавиатуры.
* Добавить понятное `focus-visible` состояние.
* Не использовать цвет как единственный способ обозначения выбранного состояния.
* Обеспечить корректную структуру заголовков.
